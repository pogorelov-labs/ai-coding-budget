# Калькулятор стоимости AI-кодинга

Запрос: сравнивать и складывать несколько личных/командных подписок и API-бюджетов GLM, OpenAI, Anthropic, DeepSeek, OpenRouter; вводить токены по моделям либо процентный mix; учитывать кеш, часы, скидки, акции, комиссии и произвольный курс USD/RUB (95 по умолчанию).

## Представление

Визуальная идея: спокойный финансовый рабочий инструмент, светлая поверхность, тёмный текст и один зелёный акцент. Без маркетингового hero и декоративных иллюстраций.

Контент: параметры команды → состав выбранного сценария → расчёт и ограничения; отдельные вкладки сравнения, каталога цен/акций и методики. Блок подписки — редактируемая единица; в нём есть модели. Ненужные подробности скрываются в раскрываемых секциях, но неопределённость результата всегда видна.

Взаимодействия: немедленный пересчёт суммы без потери фокуса ввода, короткие переходы между сценариями и раскрытие подробностей. Reduced motion соблюдается.

## Модель

- Scenario — отдельная альтернатива закупки. Его позиции складываются. Сценарии между собой не складываются.
- Line — подписка, группа одинаковых seats, API-аккаунт или OpenRouter-аккаунт. Один человек может иметь несколько lines; численность команды не равна сумме seats.
- Usage row — конкретная модель и конкретный маршрут хостинга. Вход и выход в миллионах; input включает cache hits/writes. Кеш-процент измеряется от всего input; write-процент — только от промахов кеша.
- Mix применяет доли к общему input и output позиции. Если нужны разные input/output соотношения моделей, используется явный ввод по строкам. Сумма долей должна равняться 100%; скрытой нормализации нет.
- Период: на пользователя в рабочий день, на пользователя в месяц или на всю позицию в месяц. Для квот месяц переводится в устойчивую среднюю рабочую неделю; календарные reset не симулируются.
- Fixed subscription, modeled usage, platform fees, taxes и applied grants учитываются отдельно. Показываются обычный месяц, первый платёж с annual/quarterly предоплатой и прогноз 12 месяцев при неизменных тарифах.
- USD — расчётная валюта. RUB = USD × пользовательский курс; значение 95 является настройкой, не котировкой.

## Корректность

Неизвестная включённая квота OpenAI/Anthropic не превращается в выдуманный лимит токенов. По умолчанию показывается диапазон от стоимости seats до seats плюс полностью оплаченный расход. Пользователь может указать измеренный процент покрытия; это отмечается как его допущение. Codex credits имеют отдельную ставку доллара за кредит, неизвестную без checkout, и не имеют отдельного cache-write charge.

Для GLM используются опубликованные credits, per-seat weekly и rolling 5h, модели не имеют отдельных независимых квот. При одинаковом ежедневном mix расчёт превышения пропорциональный; это оценка, не invoice reconstruction. Personal по умолчанию останавливается на лимите; отдельный PAYG fallback включается явно. Team overage отдельный переключатель. Legacy 3× нельзя умножать на новые credits; такой план допускается только как пользовательское допущение покрытия.

У OpenRouter хост выбирается явно. Нельзя складывать самый дешёвый input одного endpoint и output другого. Выходной snapshot DeepSeek может уже содержать скидку; каталог хранит канонические peak и off-peak цены. Альтернативные hosts не объявляются эквивалентными по качеству. In-region Europe не означает автоматически strict EU-only.

Акции не активируются по умолчанию. Нужны выбранная применимость и даты. Разовая скидка применяется к первому subscription invoice, а не каждому месяцу. Истёкшие предложения исключаются. Неизвестная дата окончания отмечается, цена будущего renewal не обещается. API bonus Claude — только linked eligible API/headless, не интерактивная подписка, не суммируется повторно по одному источнику.

## Доставка и проверка

Buildless HTML/JS, без внешних библиотек и backend. Каталог встроен. Один скачиваемый HTML работает без сети. Настройки сохраняются локально в браузере; JSON import/export, CSV расчёта, печать, копирование и несколько сценариев. Импорт валидируется и не исполняет HTML/JS.

Тесты: контрольные тарифные расчёты, смесь моделей, GLM weekly/5h, API часов, отсутствие двойного cache write/discount, комиссия/minimum topup/BYOK, разные циклы оплаты, разовые и истёкшие акции, неопределённые квоты, конвертация, импорт/экспорт. Browser QA: рабочие действия, desktop/mobile, offline standalone, ошибки console. Приватная публикация через Sites.

## Обновление: профиль команды

Первый шаг — три редактируемые группы активности с количеством людей и input/output на человека в день. Профиль общий для альтернатив; позиция связывается с полной командой/группой либо остаётся ручной. Количество личных подписок или командных мест — одно поле; оплаченные неиспользуемые покупки только в дополнительных настройках. GLM проверяется по группам, без объединения per-seat квот. Пустая группа без резервных мест отключает позицию. Миграция v1→v2 сохраняет прежние расходы и количества в ручном режиме.

## Технические учётки

- Отдельная группа вне human headcount; по умолчанию 0, чтобы не менять сохранённый бюджет.
- Собственный суточный token volume, календарь и часы; workers — только желаемая concurrency, не коэффициент квоты.
- Все developer audiences сохраняют прежнюю семантику, техническая группа назначается явно.
- UI показывает применимость personal/shared headless, API, supported GLM tools, Codex native service account. Сравнение и CSV сохраняют предупреждения, а не предлагают запрещённый shared seat как выгодный вариант.
- Вкладка «Автоматизация» содержит варианты, trade-offs, первичные источники, ограничения account concurrency и правила исключения двойной оплаты.
- Миграции v1/v2 → v3; токены, модели, discounts и существующие forecasts сохранены.

## Гибрид 18 + 1

Готовый шаблон добавляется отдельным сценарием с собственным профилем 3/5/10 и technical.count=1. Период human 22 дня, 09–18 MSK; server 30 дней, 24/7. Курс берётся из текущего расчёта (начальное значение 95), налог шаблона 0. Внутри шаблона можно переключать все подписки между monthly/annual, менять каждую позицию, расход и профили. Сводная таблица показывает действующие значения; пояснения отдельно обозначают исходный шаблон.

Никаких изменений старых расчётов при добавлении. `scenario.settings` — опциональный полный снимок в v3; fallback на state.settings обеспечивает совместимость. Forecast, calculateScenario, сравнение, sidebar, CSV и UI должны использовать локальные настройки. Изменение курса одного сценария не пересчитывает рубли других.

## Командный вариант GLM18 / Codex8

Собственный профиль3/5/10+server; audience active=heavy+regular. Нагрузка профиля передаётся в позицию через profileShare0–100%; внутри неё shares моделей суммируются до100%. При отключении профиля ручные токены сохраняют выделенную долю. Места считаются отдельно от доли расхода; двеGLMпозиции имеют одну org и одну квоту каждого пользователя, группы не пересекаются. Лимиты Business2–200 проверяются суммой Standard+Premium однойorg; GLM>=2, без верхней границы и без смешиванияtier. Сервер не занимает humanseat.
